# Web Client Build Guide

This folder hosts the Flutter web entry (`index.html`, `manifest.json`,
favicon, icons) and the JS bridge in `web/js`.

## Structure
- `web/index.html`: Flutter entrypoint and bootstrap.
- `web/manifest.json`: PWA manifest (icons generated by `flutter_launcher_icons`).
- `web/js`: JS bridge toolchain, output to `web/js/dist/web_bridge.js`.
- `web/tools`: build scripts for web.

## Build
### Windows
```powershell
.\web\tools\build_web.ps1
.\web\tools\build_web.ps1 -Mode release -SkipJs -SkipDeps -SkipIcons
```

### Linux/macOS
```bash
./web/tools/build_web.sh
./web/tools/build_web.sh --mode release --skip-js --skip-deps --skip-icons
```

## What the scripts do
1. Run `flutter pub get`.
2. Build JS bridge in `web/js` (unless skipped).
3. Generate web icons from `res/icon.png` via `flutter_launcher_icons` (unless skipped).
4. Download optional `web_deps.tar.gz` into `web` (unless skipped).
5. Run `flutter build web` and pass build-time defaults from env vars (if set):
   `RS_PUB_KEY`, `RENDEZVOUS_SERVERS`, `API_SERVER`.

## Local dev preview (hot reload)
```powershell
cd web\js
npm install
npm run build
cd ..\..
flutter run -d chrome
```

## Notes
- `web/js/dist/web_bridge.js` must exist before `flutter build web`.
- If you do not need the optional wasm/codec deps, pass `--skip-deps`.
